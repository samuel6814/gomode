# Social links

Public WhatsApp, Instagram, mail, and phone links are constants in [client/src/utils/contactLinks.js](../../client/src/utils/contactLinks.js).

Pages that import them include:

- [client/src/pages/user/others/ContactUs.jsx](../../client/src/pages/user/others/ContactUs.jsx)
- [client/src/pages/user/others/CommissionsPage.jsx](../../client/src/pages/user/others/CommissionsPage.jsx)
- [client/src/pages/user/others/AboutPage.jsx](../../client/src/pages/user/others/AboutPage.jsx)

The Instagram handle string used as display copy is `INSTAGRAM_HANDLE` in [client/src/theme/brand.js](../../client/src/theme/brand.js).

Edit those files to change what the site shows. Keep the real URLs and numbers out of this guide and out of git history when they are personal.
